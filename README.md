# ACEL – Real Estate Website

A modern, responsive real estate website built with **Next.js, React, TypeScript, and Tailwind CSS**, designed to showcase real estate projects, properties, locations, and company information through an engaging and interactive user experience.

## Overview

ACEL is a real estate platform focused on presenting property developments and projects through modern UI design, smooth animations, and intuitive navigation. The website provides visitors with an engaging way to explore real estate projects, discover property details, browse image galleries, and navigate different sections.

## Tech Stack

- **Next.js** – App Router and modern React development.
- **React.js** – Component-based architecture and reusable UI components.
- **TypeScript** – Static typing and maintainable code.
- **Tailwind CSS** – Responsive styling and utility-first CSS.
- **Motion** – Advanced animations and interactive transitions.
- **Nuqs** – URL query parameter management and URL-based filtering.
- **Lucide React** – Modern icon library.

## Key Features & Implementations

- Modern real estate website design.
- Responsive layouts optimized for desktop, tablet, and mobile.
- Real estate projects and property showcases.
- Interactive image galleries and carousel sections.
- Dynamic filtering using URL query parameters.
- Advanced scroll-based animations and reveal effects.
- Smooth hover interactions and page transitions.
- Reusable Google Maps integration for displaying locations.
- Dynamic and reusable React components.
- Responsive navigation and interactive UI elements.
- Optimized layouts for a consistent experience across screen sizes.

## Frontend Concepts Applied

- React component architecture and composition.
- Props, state management, and event handling.
- Conditional rendering and dynamic data mapping.
- Next.js App Router and Client/Server Components.
- URL state management using Nuqs.
- TypeScript types and interfaces.
- Reusable components and maintainable code structure.
- Responsive design principles.
- Motion-based animations and UI interactions.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000` to view the project locally.
